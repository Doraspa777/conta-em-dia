CONTA EM DIA — PWA

Esta pasta é uma Progressive Web App (PWA).
Para instalar no iPhone, o site precisa estar publicado em HTTPS. No Safari: Compartilhar > Adicionar à Tela de Início.

Arquivos:
- index.html: aplicativo
- manifest.json: configuração de instalação
- sw.js: funcionamento offline/cache
- icon-180.png e icon-512.png: ícones

Os dados de renda, meta e contas ficam salvos no armazenamento local do navegador.
